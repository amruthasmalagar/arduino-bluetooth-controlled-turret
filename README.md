# Bluetooth-Controlled Nerf Turret Using Arduino

## Project Overview
This project involves developing a Bluetooth-controlled Nerf turret using Arduino and Embedded C. It allows users to control the turret wirelessly through a smartphone using an HC-05 Bluetooth module.

The system uses three servo motors for pan and tilt movement and two DC motors for the trigger mechanism. Custom mechanical components were designed using 3D modelling and manufactured using a 3D printer.

## Objectives
- Develop a wireless smartphone-controlled turret.
- Implement Bluetooth communication using HC-05.
- Interface servo motors and DC motors with Arduino.
- Gain practical experience in Embedded C and electronics.
- Explore mechanical design and 3D printing.

## Components Used
- Arduino board
- HC-05 Bluetooth module
- 3 Servo motors
- 2 DC motors
- Motor driver circuitry
- Connecting wires and power supply
- 3D-printed components

## Working Principle
1. Commands are sent from a smartphone through Bluetooth.
2. The HC-05 module receives the commands.
3. Arduino processes the received commands.
4. Servo motors control pan and tilt movement.
5. DC motors operate the trigger mechanism.
